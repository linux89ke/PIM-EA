# Flags canonical location

This directory (pages/flags) previously contained copies of country flag SVGs. The canonical location for flag assets in this repository is the repo-root `flags/` directory.

Files in this directory have been overwritten to match the canonical `flags/` assets. To fully eliminate duplicates, run the included cleanup script (cleanup_flags.sh) from the repository root.
